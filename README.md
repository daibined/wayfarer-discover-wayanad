🌿 WAYFARER – Discover Wayanad

Discover the beauty of Wayanad, one destination at a time.

A modern tourism and destination discovery platform dedicated exclusively to Wayanad, Kerala, India.

🌐 Live Demo

"Explore WAYFARER – Visit Website" 
https://wayfarerwayanad.lovable.app

✨ Features

- Explore tourist destinations across Wayanad.
- Discover waterfalls, mountains, forests and lakes.
- Explore hidden gems and cultural heritage.
- Search and filter destinations.
- Responsive and modern user interface.

🛠️ Built With

- React
- TypeScript
- Tailwind CSS
- Vite

🎯 Purpose

Created as an academic web development project to showcase Wayanad's tourism, natural beauty and cultural heritage through a digital platform.
